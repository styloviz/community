# Styloviz Community

Questions, feedback and feature requests for [Styloviz](https://styloviz.dev),
the Angular + Tailwind CSS component library.

## Where to post

| I want to…                         | Go to                                              |
|------------------------------------|----------------------------------------------------|
| Ask how to do something            | Discussions → Q&A                                  |
| Suggest a component or feature     | Discussions → Ideas (upvote existing ideas first)  |
| Report a bug in a free package     | Issues → Bug report                                |
| Comment on a docs page             | The feedback box at the bottom of that page        |
| Show what you built                | Discussions → Show and tell                        |

## Pro license holders

Pro buyers get private support in a separate repository. Use the invite link
from your purchase email, or claim access at <https://support.styloviz.dev>.
Please don't paste Pro source code here, because this repository is public.

## Before you post

Search existing discussions and issues first. Include the package name and
version, your Angular version (Styloviz supports Angular 21 and 22), and a
minimal reproduction where you can.
